\begin{abstract}
\centering
\begin{minipage}{0.8\textwidth}
\centering
\textbf{Distributed Compute Automata} (DISCA) is a framework that enables experimentation and exploration of privacy-preserving computation approaches.
Privacy-preserving computation aims to protect the privacy of data and the computation itself. This means we don't know what the data is or what the computation is doing. 

This is a very useful abstraction that can be applied to a scenario like running a proprietary algorithm in the open web without exposing the algorithm and without users exposing their data to you.

In this work, we outline DISCA as a standard for logic and data privacy for computations.
The framework's design is proposed and we analyze in detail the performance and security from a simple prototype built on Ethereum, leveraging its blockchain properties and guarantees.
Lastly, we create a formal verification proof for the framework.
\end{minipage}
\end{abstract}

\noindent\textit{Note: Throughout this document, we use DISCA as the abbreviation for Distributed Compute Automata.}

\section{Introduction}

The framework is a technology stack that allows for both software and hardware approaches to the problem of privacy-preserving computation.

This proposal provides a much-needed playground for experimentation and exploration, a standard that would unify the approaches and provide a common interface for the development of privacy-preserving computation applications.
This flexibility is crucial given the diverse landscape of privacy-preserving computation technologies, each with their own strengths and limitations.

The reason why the framework does not just use one of the approaches is because there are trade-offs between the approaches.
For example, Homomorphic Encryption is a very powerful tool but it is computationally expensive.
TEEs are more efficient but they are more complex to implement and they are more expensive to deploy.

\subsection{Preliminaries}

Privacy-preserving methods through software are achieved through cryptography.
More specifically with privacy-preserving computation we have Homomorphic Encryption (HE) and Fully Homomorphic Encryption (FHE).
There are also cryptographic hybrid solutions that combine multiple techniques, such as Homomorphic Encryption (HE), Secure Multi-Party Computation (SMPC), and Zero-Knowledge Proofs (ZKPs), to achieve privacy-preserving computation.

On the other side of the coin, we have Trusted Execution Environments (TEEs).
TEEs are hardware-based solutions that provide a secure enclave where code and data can execute securely even in the presence of potentially compromised operating systems.
TEEs offer better performance characteristics compared to pure software-based encryption approaches, making them more suitable for practical applications.
