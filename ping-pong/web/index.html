the encrypted math — what a worker evaluates for this frame

These are DISCA opcodes, and they are the module's own wasm instructions under different names: Add is i32.add, Gt is i32.gt_s, Select is select. The lowering is 1:1 — all 174 of them, in order, arguments included, with only wasm's trailing end dropped. Nothing is folded, reordered or synthesised on the way in.

Six circuit evaluations — one whole frame — cost about 91 ns here. The same six on the DISCA network cost about 33 s: six independent jobs, three workers evaluating each under FHE, and a 2-of-3 quorum agreeing byte for byte before the board may advance. That is a factor of roughly 360 million, and it buys one thing: there, no machine computing this can see the ball.
